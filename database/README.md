# Base de datos - SocioClub

Base de datos MySQL 8.4 del TP Integrador SocioClub.

## Estructura
- socio: información de los socios.
- actividad: actividades deportivas disponibles.
- inscripcion: inscripciones de los socios a las actividades.

## Datos iniciales
- 15 socios (2 morosos).
- 8 actividades.
- 15 inscripciones activas.

## Configuración
La base de datos está alojada en Aiven y es compartida por el equipo.

El archivo socioclub_entrega.sql permite crear la estructura y cargar los datos iniciales en una base vacía.
